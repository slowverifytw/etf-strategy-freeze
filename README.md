# 主動 ETF 選股策略規則封存（v1）

這是一個公開的長期研究實驗：三套由 AI 設計的台股選股策略，規則在封存日之後不再修改，並以實盤紀錄比較表現。

目前只公開封存檔的雜湊值。規則原文與程式碼會在預定日期公開，屆時任何人都可以自行計算雜湊，確認內容和封存當天完全相同。

## 封存資訊

| 項目 | 內容 |
|---|---|
| 封存日期 | 2026-10-01（台北時間） |
| 雜湊演算法 | SHA-256 |
| 總雜湊（MANIFEST.sha256 的 SHA-256） | `6d216120f165f787cc9f05af847e0d095d4d74073f170f0794cb69f95bf23b98` |
| 預計公開原文 | 2027 年 10 月 |

## 總雜湊是怎麼算的

1. 封存資料夾 `v1/` 裡的每個檔案（規則文件與程式碼）都先統一成 UTF-8 編碼、LF 換行。
2. 對每個檔案計算 SHA-256，依路徑排序寫成 `MANIFEST.sha256`（標準 `sha256sum` 格式）。
3. 再對 `MANIFEST.sha256` 本身計算 SHA-256，得到上表的總雜湊。

只要任何一個檔案改了一個字，對應的檔案雜湊就會不同，總雜湊也會跟著不同。

## 公開原文後如何驗證

下載公開的 `v1/` 資料夾（建議下載 ZIP，避免 Git 在 Windows 上自動轉換換行），在 `v1/` 資料夾裡執行：

**macOS**

```
shasum -a 256 -c MANIFEST.sha256
shasum -a 256 MANIFEST.sha256
```

**Linux**

```
sha256sum -c MANIFEST.sha256
sha256sum MANIFEST.sha256
```

**Windows（PowerShell）**

```
Get-FileHash MANIFEST.sha256 -Algorithm SHA256
```

（Windows 需逐一對 MANIFEST.sha256 內列出的檔案執行 `Get-FileHash`，比對每一行的值。）

判斷方式：

1. 第一個指令每個檔案都顯示 `OK`，代表檔案內容與清單一致。
2. 第二個指令算出的值，必須等於上表的總雜湊 `6d216120…bf23b98`。

兩項都符合，就代表公開的規則與程式和 2026-10-01 封存的版本相同。
